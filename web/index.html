What it is

A lot of AI coding breaks down before the first prompt. The goal is fuzzy, there are no shared conventions, and nothing records why past choices were made. This template is where you settle those things first.

It gives the agent context to work from instead of guessing, and gives you a short planning chain to run before any code exists. Small enough project? Skip the chain. It says so.

Six context types

Every piece of context has one home, so nothing gets lost or duplicated.

InstructionsAGENTS.md. Always loaded, kept short.
Knowledgedocs/. Loaded when a task needs it.
MemoryADRs. Why a choice was made.
ExamplesReal code from the project, not invented.
ToolsMCP and API definitions, plus when to use them.
GuardrailsHooks, lint rules, the security section.

The planning chain

Six short documents, filled in order before coding starts. Roughly ten minutes each. If the project is small enough, the chain tells you to skip it and start coding.

  1. Brief. What we're building, for whom, why now.
  2. Stack decision. A set of questions to answer, not a fixed answer.
  3. Architecture sketch. Rough, and expected to change.
  4. Extension points. Growth you expect, without building for it yet.
  5. Milestones. Build order, and what waits.
  6. Deploy strategy. Where the code lands.

Get it

Copy the files into a new project, or use the repository as a GitHub template. Start with docs/planning/README.md. It tells you when to run the chain and when to skip it. All of it is MIT licensed.
